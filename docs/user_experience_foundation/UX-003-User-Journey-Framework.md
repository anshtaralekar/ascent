# User Journey Framework

> "Every interaction should move the user one step closer to becoming who they want to be."

## Purpose

This document defines the complete lifecycle of an Ascend user, from discovering the product to building long-term habits and achieving meaningful goals.

---

# Journey Philosophy

Ascend is not designed for one productive day.

It is designed to support years of sustainable growth through small, consistent improvements.

---

# Journey Stages

## Stage 1 — Discover

The user learns about Ascend through recommendations, social media, or the website.

Goals:

- Understand the value proposition
- Build trust
- Encourage installation

Success Metric:
- App installed

---

## Stage 2 — Onboarding

The first session should establish clarity without overwhelming the user.

Steps:

- Create account
- Choose goals
- Select focus areas
- Configure AI preferences
- Import existing tasks (optional)

Success Metric:
- User reaches the dashboard in under five minutes.

---

## Stage 3 — First Win

Within the first session, the user should accomplish something meaningful.

Examples:

- Create a task
- Add a habit
- Schedule an event
- Create a goal

Success Metric:
- First completed action

---

## Stage 4 — Daily Loop

Typical daily flow:

Dashboard → Tasks → Calendar → Focus Session → Journal → End-of-day Reflection

The dashboard should always answer:

- What matters today?
- What is next?
- How am I progressing?

---

## Stage 5 — Weekly Review

Once a week, Ascend encourages reflection.

Review includes:

- Completed work
- Habit consistency
- Goal progress
- AI insights
- Planning for next week

---

## Stage 6 — Long-Term Growth

Over time Ascend should help users:

- Build lasting habits
- Achieve goals
- Improve consistency
- Learn from past decisions
- Reduce planning effort through AI

---

# Journey Design Principles

- Minimize friction.
- Reward meaningful progress.
- Reduce decision fatigue.
- Keep users in control.
- Encourage reflection over perfection.

---

# Engineering Notes

Analytics events should align with each journey stage to measure user progression and identify drop-off points.

---

# AI Context

AI should adapt its guidance based on the user's current journey stage instead of using a one-size-fits-all approach.
