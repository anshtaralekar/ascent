# Illustration System

> "Illustrations should explain, reassure, and inspire. They should never exist only to fill empty space."

## Purpose

This document defines the illustration language for Ascend, ensuring every illustration feels cohesive, purposeful, and unmistakably part of the brand.

---

# Philosophy

Illustrations support understanding and emotion.

They should simplify concepts, celebrate progress, and soften complex moments without distracting from the user's work.

---

# Core Principles

## Purposeful

Every illustration should communicate something meaningful:

- Empty states
- Success moments
- Errors
- Onboarding
- Learning
- AI interactions

---

## Human-Centered

Illustrations should celebrate people, ideas, and growth.

Avoid exaggerated mascots or distracting characters.

---

## Minimal Complexity

Use:

- Clean geometric forms
- Soft curves
- Limited detail
- Consistent perspective

Avoid visual clutter.

---

# Visual Style

Preferred characteristics:

- Flat with subtle depth
- Soft gradients only when meaningful
- Rounded geometry
- Balanced whitespace
- Calm compositions

---

# Color Usage

Illustrations inherit semantic colors from the Color System.

Accent colors should highlight focus rather than dominate the artwork.

---

# Empty States

Every empty state should:

- Explain why the screen is empty
- Suggest the next action
- Reduce user anxiety
- Reinforce the brand personality

---

# Success Moments

Celebrate meaningful milestones with restrained delight.

Examples:

- Completing a goal
- Finishing a project
- Reaching a habit milestone

Avoid excessive celebration for routine actions.

---

# AI Visual Language

AI-related illustrations should communicate:

- Guidance
- Discovery
- Clarity
- Collaboration

Avoid imagery suggesting AI is replacing the user.

---

# Accessibility

Illustrations must never contain essential information that is unavailable through text.

Provide meaningful alternative text where appropriate.

---

# Engineering Notes

Illustrations should be delivered as scalable vector assets whenever possible and optimized for light and dark themes.

---

# AI Context

Future AI-generated artwork should follow this illustration language to maintain visual consistency.
