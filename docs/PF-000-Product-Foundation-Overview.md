# Product Foundation Overview

> *Every great product begins with a clear understanding of why it exists.*

## Purpose

This document is the entry point to the Ascend documentation system. Every contributor, whether human or AI, should read this document before moving to any other volume.

The goal is simple:

> **Remove assumptions before writing code.**

## Scope

This document defines:

- Documentation philosophy
- Documentation hierarchy
- Repository organization
- Reading order
- Guiding principles

## About Ascend

Ascend is an AI-powered Life Operating System.

Unlike traditional productivity applications that organize work, Ascend helps people intentionally evolve into the person they aspire to become.

Tasks are not the product.

Transformation is the product.

## Documentation Philosophy

Good documentation reduces ambiguity.

Great documentation removes it.

Every important decision should be documented with its reasoning so future contributors never have to guess.

## Guiding Principles

1. Clarity over cleverness.
2. Decisions require reasoning.
3. Consistency beats preference.
4. Simplicity before complexity.
5. User transformation before productivity.

## AI Context
