# Success Metrics

> "Success is measured by meaningful improvement in people's lives, not by how often they open the app."

## Purpose

This document defines how the success of Ascend is measured.

These metrics guide product strategy, feature evaluation, and long-term development.

Every major feature should positively influence at least one metric defined here.

---

# Philosophy

Traditional software often measures:

- Daily Active Users
- Time spent
- Notification opens
- Session duration

These metrics are useful for understanding usage, but they are not indicators of genuine user success.

Ascend measures user progress before product engagement.

---

# Primary Success Metrics

## 1. Goal Completion Rate

Measures the percentage of meaningful goals completed over time.

Success means users consistently move toward long-term objectives rather than only completing short-term tasks.

---

## 2. Habit Consistency

Tracks sustainable routines instead of perfect streaks.

Recovery after missed days is considered a positive outcome.

---

## 3. Planning Confidence

Users should increasingly trust their plans.

Signals include:

- Fewer abandoned plans
- Lower schedule churn
- Improved estimation accuracy

---

## 4. Reflection Frequency

Users regularly review their progress and learn from previous actions.

Reflection is a core part of the growth loop.

---

## 5. AI Recommendation Acceptance

Measures whether AI suggestions are considered genuinely useful.

High acceptance should come from quality recommendations, not aggressive prompting.

---

# Product Health Metrics

These help evaluate the application itself.

- Crash-free sessions
- Synchronization reliability
- Search performance
- AI response quality
- Task completion latency
- Accessibility compliance

---

# Metrics We Avoid Optimizing

Ascend will never optimize solely for:

- Screen time
- Endless scrolling
- Notification volume
- Daily login streaks
- Artificial engagement

If these increase while user outcomes decline, they should be treated as warning signals.

---

# North Star Metric

**Meaningful Progress Rate**

Definition:

The percentage of users who consistently make measurable progress toward self-defined long-term goals over sustained periods.

This metric combines:

- Goal completion
- Habit consistency
- Reflection
- Planning quality
- User satisfaction

---

# Decision Framework

Before shipping a feature, ask:

- Which success metric improves?
- How will improvement be measured?
- Can success be validated objectively?
- Does this encourage healthier behavior?

---

# AI Context

Future analytics, dashboards, and machine learning models should prioritize these metrics when evaluating user progress.
