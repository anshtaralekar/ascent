# Animation

> "Motion should communicate change, never compete for attention."

## Purpose

Defines animation standards used throughout Ascend to create a responsive, understandable, and delightful experience.

---

## Philosophy

Animation should:

- Explain transitions
- Reinforce hierarchy
- Provide feedback
- Maintain continuity
- Respect user preferences

Decorative motion should always be secondary to functional motion.

---

## Animation Categories

- Page Transitions
- Component Transitions
- Microinteractions
- Hover Effects
- Focus Animations
- Loading Animations
- Success Animations
- Error Animations
- AI Streaming
- Gesture Animations

---

## Principles

- Fast
- Consistent
- Predictable
- Interruptible
- Accessible

---

## Performance

Target:

- 60 FPS
- GPU-accelerated transforms
- Minimize layout recalculations
- Respect reduced motion preferences

---

## Interaction

Animations should support:

- Hover
- Click
- Drag
- Swipe
- Expand / Collapse
- Navigation
- Dialogs
- Notifications

---

## Accessibility

Provide:

- Reduced motion mode
- Non-animated alternatives
- Clear focus transitions
- Screen reader compatibility

---

## Tokens

Uses:

- Motion Tokens
- Duration Tokens
- Easing Tokens

---

## Engineering Notes

Implement reusable animation primitives using standardized timing, easing, and transition utilities.

---

## AI Context

AI interactions should use consistent streaming, thinking, and completion animations.
