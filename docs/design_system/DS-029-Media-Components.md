# Media Components

> "Media should enrich productivity without distracting from it."

## Purpose

Defines all reusable media components used throughout Ascend.

---

## Philosophy

Media components should prioritize clarity, performance, accessibility, and responsiveness.

---

## Supported Components

- Avatar
- Profile Picture
- Image
- Cover Image
- Image Gallery
- Video Player
- Audio Player
- File Attachment
- Document Preview
- PDF Preview
- File Upload
- Drag & Drop Zone
- AI Generated Media

---

## Anatomy

- Preview
- Metadata
- Actions
- Progress Indicator
- Status Badge

---

## States

- Empty
- Uploading
- Processing
- Ready
- Error
- Downloading
- Disabled

---

## Interaction

Support:

- Drag & Drop
- Click to Upload
- Preview
- Download
- Share
- Replace
- Delete
- Zoom (images)

---

## Accessibility

- Alt text
- Captions
- Transcripts
- Keyboard navigation
- Screen reader support
- WCAG contrast

---

## Performance

- Lazy loading
- Responsive images
- Progressive loading
- Media optimization
- Caching

---

## Tokens

Uses:

- Color
- Typography
- Radius
- Spacing
- Motion
- Elevation

---

## Engineering Notes

Implement reusable media primitives with responsive rendering, upload handling, previews, and accessibility built in.

---

## AI Context

AI-generated media should use the same presentation components while clearly identifying generated content.
