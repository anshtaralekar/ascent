# Icons

> "Icons should reinforce meaning, never replace it."

## Purpose

This document defines the iconography system for Ascend, ensuring every icon is consistent, recognizable, accessible, and reusable.

---

# Icon Philosophy

Icons should simplify recognition and reduce cognitive load.

Text should remain the primary method of communication. Icons enhance clarity but should not replace labels for important actions.

---

# Icon Categories

Standard categories include:

- Navigation
- Actions
- Status
- Files
- Communication
- Productivity
- Calendar
- Goals
- Habits
- AI
- Settings

---

# Visual Style

All icons should share:

- Consistent stroke width
- Rounded geometry
- Optical alignment
- Unified corner treatment

Avoid mixing different icon styles.

---

# Standard Sizes

Supported sizes:

- 16 px
- 20 px
- 24 px (default)
- 32 px

Components should reference icon size tokens.

---

# Usage Rules

Icons may appear:

- Before labels
- After labels
- Standalone (only when universally understood)

Avoid excessive decorative icons.

---

# Accessibility

Standalone icons must include accessible labels.

Icons must never be the sole method of conveying critical information.

---

# Engineering Notes

Use optimized SVG assets with reusable icon components supporting color, size, accessibility labels, and theme adaptation.

---

# AI Context

AI-generated interfaces should use approved icons from the design system rather than generating custom iconography.
